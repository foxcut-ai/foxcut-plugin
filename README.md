# FoxCut

[FoxCut](https://foxcut.ai) is a directable AI video studio. This plugin puts that studio in Cursor over MCP: camera-directed motion, locked characters, talking avatars, product shots, and UGC ads, using the same catalog and credits as the web app.

Search this plugin for: AI video generator, text to video, image to video, camera control, talking avatar, consistent characters, Kling, Sora, Veo, UGC ads, product video.

## What it does

- **AI video generation** with camera-directed presets (dolly, orbit, crane, FPV, and the rest of the move list).
- **Text to video** and **image to video** across the live FoxCut catalog, including Kling, Sora, Veo, Seedance, Hailuo, and Wan.
- **AI image generation and edit** (product photos, campaign stills, upscale).
- **Talking avatars** with voice and lip sync.
- **Consistent characters** that hold across shots.
- **Storyboard, edit, upscale, and assemble** without leaving the agent thread.
- **Credit estimates before spend.** Catalog, plan, and estimate tools are read-only. Generation bills the connected FoxCut account after you confirm.

MCP endpoint: `https://mcp.foxcut.ai/mcp`

Install opens FoxCut OAuth. No API key is pasted into the plugin.

Homepage: https://foxcut.ai/mcp

## Try it

- "Show my FoxCut plan and credit balance."
- "Recommend a model for a five-second vertical product clip and estimate the cost."
- "Generate a camera-directed UGC product video from this still, but ask before spending credits."
- "Create three product-photo concepts, then a talking-avatar take that keeps the same character."
- "List my recent generations and tell me which are ready."

## Local check

Copy or symlink this directory to `~/.cursor/plugins/local/foxcut`, reload Cursor, and confirm FoxCut appears under Customize.
